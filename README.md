# Ammar Portfolio

Personal portfolio website for Mohammad Ammar Ghanchi, a Digital Marketing Executive and Performance/Growth Marketing Consultant.

## Run locally

Open the project folder in a terminal and run:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:4173`.

## Stack

Semantic HTML, CSS and small vanilla JavaScript enhancements. No build step is required.
